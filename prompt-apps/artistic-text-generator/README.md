# ✨ Artistic Text Prompt Generator

A playful, feature-rich web application that generates sophisticated AI prompts for creating stunning artistic text and typography designs.

## What It Does

Artistic Text Prompt Generator is an interactive prompt architect that helps creators craft professional-grade AI prompts specifically optimized for generating beautiful artistic text designs. Instead of manually writing complex prompts, users input their text, select artistic styles and moods, and the app generates detailed, ready-to-use prompts for AI image generators.

Perfect for creating:
- Artistic typography designs
- Decorative text art
- Calligraphy-inspired designs
- Abstract letter formations
- Text-based visual art

## How It Works

### 1. **Enter Your Text**
   - Type any word or phrase you want to render as art
   - Examples: "DREAMS", "SERENITY", "ELECTRIC", "WONDER"

### 2. **Choose Artistic Style**
   Select how you want your text to look:
   - **Liquid Mercury** - Fluid, flowing metallic effect
   - **Crystalline Ice** - Sharp, geometric, frozen aesthetic
   - **Molten Lava** - Fiery, volcanic energy
   - **Golden Filigree** - Ornate, delicate craftsmanship
   - **Neon Glow** - Electric, vibrant tubes
   - **Nature Moss** - Organic, earthy textures
   - **Cosmic Nebula** - Galactic, ethereal beauty
   - **Mirror Reflection** - Polished, symmetrical
   - **Sand Sculpture** - Granular, textured
   - **Glass Transparency** - Clear, fragile

### 3. **Pick Your Mood/Theme**
   Set the emotional atmosphere:
   - Mystical Ethereal
   - Vibrant Energetic
   - Calm Serene
   - Dark Moody
   - Luxurious Elegant
   - Chaotic Wild
   - Minimalist Clean
   - Surreal Dreamlike

### 4. **Select Artistic Technique**
   Choose the creation method:
   - 3D Sculpting
   - Digital Painting
   - Photography Macro
   - Sculpture Carved
   - Mixed Media
   - Watercolor Expressive
   - Oil Painting Thick
   - Conceptual Abstract

### 5. **Adjust Settings**
   - **Resolution**: 8K Ultra, 4K Cinematic, or High Def
   - **Mode**: Detailed (comprehensive prompts) or Simple (quick generation)

### 6. **Generate & Copy**
   - Click in any field to auto-generate
   - One-click copy to clipboard
   - Real-time character count

## How to Use

1. Open `index.html` in any modern web browser
2. Type or paste your text (word or phrase)
3. Select your preferred artistic style
4. Choose a mood/theme that matches your vision
5. Pick an artistic technique
6. Adjust resolution and mode if desired
7. Watch the prompt generate in real-time
8. Click "Copy Prompt" to copy to clipboard
9. Paste into your favorite AI image generator (Midjourney, DALL-E, Gemini, etc.)

## Tips for Best Results

- **Shorter Text** - 1-3 words work best for clarity
- **Specific Adjectives** - Combine styles for unique results
- **Detailed Mode** - Use for high-quality, publication-ready designs
- **Simple Mode** - Quick experimentation and testing
- **Presets** - Use them as starting points, then customize
- **Resolution** - 8K for detailed work, 4K for balanced results
- **Experiment** - Try different style/mood/technique combinations
